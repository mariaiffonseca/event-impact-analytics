# Engineering Stack

> Version: 1.0.0
> Status: Living Document
> Last Updated: 2026-08-08

## Purpose
Defines the engineering standards shared across all portfolio projects.

## Engineering Principles
- Simplicity over cleverness
- Solve the problem first
- Architecture before implementation
- Modular by default
- Test behaviour, not implementation
- Documentation explains WHY
- AI is an engineering assistant
- Continuous Learning

## Architectural Principles
- Prefer pragmatic architecture.
- Introduce abstractions only when justified.
- Repository is the data boundary.
- Keep features independent.

## Definition of Done
- Code implemented
- Tests written
- Lint passes
- Documentation updated
